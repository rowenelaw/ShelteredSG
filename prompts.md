# Project Prompts — ShelteredSG

This file collates all user prompts used to build **ShelteredSG**, a rain-aware Singapore bus routing and live arrival frontend application.

---

## Prompt 1 — Initial Application Specification

> 1. build me a singapore based bus application that suggests most efficient bus route taking into considerations these factors:
> a) weather (minimise exposure to outdoor rain)
> b) shortest travel time 
> c) shortest travel distance
>
> 2. tracks real time bus arrival times
>
> 3. tracks real time weather rain situation
>  
> 4. include search bar to input actual start and end location of travel journey
>
> 2. build just the front end for now, i will establish an api connection later.
